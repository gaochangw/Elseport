# Elseport 桌面界面设计 01

用户已选定 Elseport。本轮交付品牌和界面原型，等待视觉与交互方向确认后再实现产品 UI。示例仅包含 Ubuntu/Linux，数据、桌面、进度和文件均为模拟，不连接真实虚拟电脑。

## 设计目标

用户不必先理解虚拟化。第一次打开只需知道“这里能创建另一台电脑”；再次打开，最重要的操作是继续上次的工作。资源参数有能直接使用的默认值，高级选项保留但不抢占主要流程。

每屏最多一个主要按钮。入口位置固定；出错时保留用户输入和已下载文件，说明如何继续。界面不承诺未经验证的速度、应用兼容性或安全效果。

## 信息结构与流程

侧栏分为虚拟电脑、恢复点、设置、关于。创建入口始终在虚拟电脑页顶部，与当前选择无关，不再需要回到一个隐藏的首页。

```text
首次打开 → 创建电脑 → 下载 → 校验 → 安装 → 准备就绪 → 运行
                       ↓                        ↓
                    中断 / 重试              暂停 / 继续
                       ↓                        ↓
                    保留进度                保存并关闭

虚拟电脑列表 → 设置 / 恢复点 / 继续使用
```

| 画面 | 主要动作 | 关键决定 |
| --- | --- | --- |
| 首次打开 | 创建第一台虚拟电脑 | 单一推荐系统；自带镜像是次级入口 |
| 列表与详情 | 继续使用 / 启动 | 明确区分已保存、已关闭；新建入口持续可见 |
| 创建电脑 | 创建并安装 | 名称、使用者、密码在一页；右侧显示资源默认值 |
| 下载 | 允许暂停与继续 | 不编造完成时间；已下载数量和校验步骤可见 |
| 校验 | 等待 | 明确是完整性校验；不写成认证或兼容保证 |
| 安装 | 等待 | 不宣称固定分钟数；保持开机提示 |
| 安装完成 | 打开电脑 | 把完成转换为可操作状态 |
| 下载中断 | 继续下载 | 不用错误码；说明已保留内容和网络检查方法 |
| 空间不足 | 重新检查 | 显示可用和需要的空间；不会自动删除用户文件 |
| 常用设置 | 保存设置 | 内存与处理器可调；配置约束在产品实现中接入 |
| 共享 | 保存设置 | 剪贴板和文件夹默认关闭；明确双向读取的含义 |
| 显示 | 保存设置 | 以“舒适”“清晰”说明取舍，而非强迫理解比例 |
| 恢复点 | 创建恢复点 | 恢复前提示当前状态被替换；保留撤销操作空间 |
| 运行窗口 | 使用客体 | 常用动作在紧凑工具栏；从图标可获得文字标签 |
| 暂停 / 保存 | 继续 / 等待 | 区分暂停和保存，不用同一种空白画面表示 |
| 关闭确认 | 保存并关闭 | 正常关机是次级动作；强制关闭还要再次确认 |
| 关于 | 查看许可证 | 来源、版权、无担保、再分发权和完整许可入口 |

“全屏预览”“专注视图”只演示窗口布局，没有操作系统级切换，也不证明客体无缝显示可用。产品接入前要单独验证显示、焦点、输入法和辅助功能。

## 视觉系统

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| Surface | `#FFFFFF` | `#20212E` | 主工作区 |
| Surface subtle | `#F7F7FB` | `#262735` | 次级容器 |
| Sidebar | `#F5F4F9` | `#1B1C28` | 持续导航 |
| Foreground | `#242337` | `#F1F0F8` | 主文字 |
| Muted | `#6B6A7D` | `#AAA8BD` | 说明文字 |
| Accent | `#6252CF` | `#AA99FF` | 主动作与选中态 |
| Accent subtle | `#EDEAFA` | `#37304E` | 弱强调 |
| Border | `#E5E3ED` | `#383848` | 容器与分隔 |
| Success | `#27805F` | `#87D5AF` | 正常状态，伴随文字 |
| Warning | `#97601B` | `#ECC17A` | 可恢复问题，伴随说明 |
| Danger | `#BE4051` | `#F697A4` | 强制关闭等风险操作 |

- 字体：界面用平台默认无衬线字体；英文品牌使用本地 Manrope。没有嵌入 Apple 字体或符号资源。
- 字级：主标题 30 px，首次打开 38 px，分组标题 19 px，正文 13–14 px，辅助信息 11–12 px。用户输入和重要警告不使用极小字。
- 字重：正文 400，按钮 600，标题 650；字标由单独的转曲资源提供。
- 间距基准：4 px，常见间距 8 / 12 / 16 / 24 / 32。内容区 38 px；紧凑窗口自动减小。
- 圆角：输入和按钮 8–9 px；容器 12–15 px；主窗口 17 px。图标的内部圆角独立控制。
- 动效：开关位移 150 ms；不采用持续闪动、强制弹跳或无意义庆祝。降低动态效果时关闭过渡。
- 状态：文字与图标共同表达，不仅依赖红绿颜色。

## 组件清单

应用标题栏、固定侧栏、电脑选择项、详情卡、状态标签、主/次/轻量按钮、带标签输入框、资源滑块、共享开关、分组标签页、进度条与步骤、可恢复错误块、时间线、确认对话框、非阻塞反馈、运行工具栏。

组件在浅/深模式下用同一套语义 token，避免分支样式逐屏漂移。图形是本项目自行绘制的 SVG；客体桌面是合成示意，不是操作系统截图。

## 语言与文案

完整中英对照见 [COPY.md](COPY.md)。界面使用“虚拟电脑”“增强功能”“恢复点”。Ubuntu、Elseport、GPL、GB 等专名或单位可保留原文；技术标识只出现在需要的高级说明或法律来源中。

中文不逐字翻译英文。两种语言分别控制标题长度和动词，不承诺相同字数。实际产品需要将确认后的文案移入现有翻译系统，不能靠 HTML 原型证明翻译已集成。

## 辅助功能与窗口约束

参考 [Apple HIG：Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) 的可感知、可操作、适应用户设置等原则；没有复制其中的图片、符号或界面资产。

- 默认目标为 1470 × 956 点屏幕；同时检查 1280、980、390 px 宽度下的布局，不以手机外观替代桌面设计。
- 所有按钮使用原生 button；图标按钮提供标签；输入框有明确关联 label。
- 标题和内容具有语义层级；进度使用 progressbar；状态反馈使用 live region。
- 键盘可切换设置标签、操作滑块；弹窗约束焦点，Escape 取消；清楚显示键盘焦点。
- 提供高对比度预览开关，并响应 prefers-contrast 与 prefers-reduced-motion。
- 不申请辅助功能或屏幕录制权限，不发送宿主键盘事件，不接触真实剪贴板。
- 浏览器辅助树与键盘测试可核查结构；**尚未做真人 VoiceOver 测试，不能标为无障碍验收通过。**

## 原型的边界

这是局部状态驱动的 HTML 原型，不是新前端实现，也不创建、启动或修改虚拟电脑。密码仅为示例，不保存；名称作为文本转义。没有联网下载、遥测、账号或外部字体请求。

使用顶部预览栏切换画面、中英文和主题；原型中的创建、暂停、恢复、设置、关闭会操作模拟状态。下载流程在交互模式中自动演示；带 `static=1` 的链接停在固定画面，便于检查。

验收记录见 [VALIDATION.md](VALIDATION.md)。实际产品的既有端到端测试、虚拟电脑生命周期、客体显示及输入仍需在实现阶段运行。
