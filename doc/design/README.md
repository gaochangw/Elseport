# Elseport 品牌与界面提案

用户已确定产品名为 Elseport。本目录提供可点击界面原型、品牌预览、设计规范及双语文案；品牌完整资源位于仓库的 `brand/`。

## 打开预览

在仓库根目录启动仅供本机访问的预览服务：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory doc/design
```

然后打开 `http://127.0.0.1:8765/?lang=zh`。英文预览使用 `?lang=en`。总览只展示当前语言的浅色界面大图。服务仅展示这个设计目录，无需登录、安装依赖或启动虚拟电脑。结束后可在运行服务的终端按 Ctrl+C。

- 总览：`index.html`
- 品牌：`brand.html`
- 交互原型：`prototype/index.html`

顶部预览栏可切换语言、主题及画面。可以实际点击创建入口、填写示例表单、暂停下载、操作共享开关、创建恢复点和确认保存。所有操作只影响当前浏览器里的示例状态。请不要输入真实密码。

本目录没有连接 Main API，不是可启动客体的产品。设计确认后才进入现有前端的实现与真实测试。不要把演示截图当作已经实现功能的证据。
